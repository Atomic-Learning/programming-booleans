In programming, a **boolean** is a data type that represents truth values. A boolean can have one of exactly two values: `true` or `false`. These two values are the only possible values for any boolean variable in any programming language.

# Boolean Values

The two boolean values are:

* `True`: Represents affirmative or positive truth
* `False`: Represents negation or negative truth

Different programming languages may use different conventions for representing these values (some use `true` and `false`, others use `True` and `False`, and some even use 1 and 0), but the concept is identical across all languages.
